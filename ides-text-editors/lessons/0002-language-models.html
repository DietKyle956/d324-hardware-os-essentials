Language Models: Compiled vs Interpreted

Two ways code becomes a running program. Know which languages compile and which are interpreted.

The win

By the end of this lesson you'll know Java and C/C++ are compiled (Q28), while Python and scripting languages are interpreted.

The two models

ModelHow it runsExamples
CompiledTranslated to machine code first, then runJava, C, C++
Interpreted / scriptingRun line-by-line by an interpreterPython, JavaScript, shell scripts

A compiled language is converted to machine code by a compiler before execution. Java and C/C++ are the compiled examples the exam uses. (Java compiles to bytecode, then runs on a virtual machine.)

An interpreted/scripting language is read and executed line-by-line by an interpreter at runtime, with no separate compile step. Python and shell scripts are examples.

The trap

The exam lists "Java and C/C++" as the compiled answer. Don't overthink Java's bytecode step — in this course's model, Java and C/C++ = compiled. Python and scripting = interpreted.
