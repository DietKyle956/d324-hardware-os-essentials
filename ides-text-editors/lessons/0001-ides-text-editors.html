IDEs vs Text Editors

Two tools for writing code. Know which one debugs and which one just customizes.

The win

By the end of this lesson you'll know Visual Studio Code is the IDE for debugging and running code (Q27), and Atom is the customizable text editor (Q29).

The two tools

ToolWhat it isBest for
IDE (integrated development environment)All-in-one: editor + debugger + compiler/runnerWriting, testing, and debugging full programs
Text editorLightweight editor, often highly customizableEditing code/files, quick edits

An IDE bundles everything a developer needs — syntax highlighting, built-in debugging, and code execution — in one place. Visual Studio Code is the example the exam uses for writing and testing Python scripts.

A text editor is simpler and faster, but some are very customizable and support many languages. Atom is the example the exam uses for a customizable editor.

The trap

"Built-in debugging, syntax highlighting, and code execution" = IDE (VS Code). "Customizable editor supporting many languages" = text editor (Atom). Match the features to the tool type.
