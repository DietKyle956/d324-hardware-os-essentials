Paradigms and Tools: OOP and PowerShell

One language that models the world in objects, and one shell that runs cmdlets.

The win

By the end of this lesson you'll know C++ is an object-oriented language (Q30), and PowerShell is the tool that uses cmdlets (Q31).

Object-oriented programming (OOP)

OOP organizes code around objects that bundle data and behavior. C++ is the object-oriented language the exam uses. In contrast, SQL is a query language, HTML is markup, and C is procedural (not object-oriented).

PowerShell and cmdlets

PowerShell is Microsoft's command-line scripting tool. Its commands are cmdlets (pronounced "command-lets") — small, single-purpose commands like Get-Process or Stop-Service. Each cmdlet performs a specific function and follows a Verb-Noun naming pattern.

The trap

"Cmdlet (command-let) that performs a specific function" = PowerShell, not JavaScript, HTML, or batch scripts. And for OOP, remember: C++ = object-oriented; C, SQL, and HTML are not.
