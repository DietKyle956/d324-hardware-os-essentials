Web-stack Roles: Front-end vs Back-end

Two halves of a web app, and the databases behind the back end.

The win

By the end of this lesson you'll know TypeScript is a front-end skill (Q48), MongoDB is a cloud back-end database (Q49), and CouchDB handles document-based data (Q50).

Front-end vs back-end

SideWhat it doesExamples
Front-endThe user interface — what runs in the browserTypeScript, JavaScript, Angular
Back-endServers, logic, and databases behind the scenesNode, PHP, Java, MongoDB, MySQL

The front end is everything the user sees and clicks. TypeScript (a typed JavaScript) is a front-end skill, so it's relevant for a front-end team.

The back end runs on servers and stores data. MongoDB (often just "Mongo") is a back-end database popular in cloud-based solutions. CouchDB is a document database, so it's the right tool for an organization handling document-based data. MySQL is a relational (SQL) database.

The trap

Front-end = browser/UI (TypeScript). Back-end database = Mongo (cloud). Document data = CouchDB. Don't mistake JSON (a data format) or Node (a runtime) for a database.
