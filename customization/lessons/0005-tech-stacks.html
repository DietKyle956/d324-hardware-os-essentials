Tech Stacks and Web Servers

Why teams adopt a stack, the simplest web server, and the front-end framework.

The win

By the end of this lesson you'll know Apache is the basic web server (Q52 — the one you missed), and why stacks deliver flexibility (Q51) and efficiency (Q54).

Why adopt a tech stack

A tech stack is the set of languages, libraries, frameworks, and tools a project is built with. Two of the reasons the exam asks about:

ReasonWhen it applies
FlexibilityRequirements evolve and the team needs to modify the project as it progresses
EfficiencyPre-existing code, libraries, and frameworks are already integrated

The tools

ToolWhat it is
ApacheA simple, basic web server — the right pick for a small business
Django / Ruby on Rails / PHPFrameworks/languages for building apps (more than a basic web server)
AngularA front-end framework

Apache is the simplest tool for just serving web pages. A small business that needs a basic web server wants Apache, not a full application framework like Django or Rails.

The trap

"Simple web server for a small business" = Apache — a web server, not a framework. Django, Rails, and PHP are for building applications on top. And Angular is front-end; Spring and Django are back-end frameworks.
