Cloud Characteristics Cheat Card

CharacteristicExam tell
On-demand self-service"self-service, no provider interaction"
Broad network access"phones, laptops, workstations"
Resource pooling"various clients/devices access pooled resources"
Rapid elasticity"scale up/down quickly"
Measured service"track usage and bill"

Memory hook

Many clients share pooled resources = resource pooling. Track & bill = measured service. Don't swap them.
