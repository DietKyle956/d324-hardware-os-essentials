RAM Technologies: DRAM, SRAM, and Clock Signals

Four RAM types that the exam tests as look-alike pairs. Learn the refresh question and the clock question, and Q15 + Q16 become free points.

The win

By the end of this lesson you'll know which RAM needs refreshing, which one shares a clock, which one doesn't — and you'll get the one you missed (Q15) right every time.

DRAM vs SRAM — the refresh question

DRAM (dynamic RAM) stores each bit as a tiny charge in a capacitor. Capacitors leak, so DRAM must be refreshed constantly — thousands of times a second — or it forgets. It's cheap and dense, which is why main memory is DRAM.

SRAM (static RAM) stores each bit in a flip-flop circuit that holds its state without refreshing. It's faster than DRAM but pricier and bulkier per bit — which is why L1/L2/L3 cache is built from SRAM, not DRAM.

Synchronous vs asynchronous — the clock question

The exam's matched pair (Q15 and Q16) is really one idea: does this RAM share the CPU's clock or not?

  • Synchronous DRAM (SDRAM) — shares a common clock signal with the computer's system bus. "Synchronous" = same clock, same timing.
  • Asynchronous DRAM — independent of the CPU's external clock. It runs on its own timing and doesn't share that clock signal.

Memory hook

Sync = same clock. Async = its own clock. The question gives you the definition ("shares a clock" / "independent of the clock") and asks for the word — so just match the prefix.

DDR SDRAM — double data rate

DDR SDRAM is synchronous DRAM that transfers data on both edges of the clock signal instead of one, effectively doubling throughput. It's the same "shares a clock" family as SDRAM — just faster.
