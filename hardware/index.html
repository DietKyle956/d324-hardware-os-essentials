Hardware

Storage, memory, and the CPU: hard-drive anatomy, SSDs, RAM and cache, and keeping a machine cool.

Lessons

LessonWhat you learnStatus
1 - Hard Drive Anatomy: Where Data Actually LivesOne small lesson that settles the question you missed — and gives you a mental model for every storage question that follows.Ready
2 - SSD vs HDD: The Trade-OffsTwo ways to store the same bits — one mechanical, one electronic. Learn which one wins on speed, cost, capacity, and endurance so you can answer any "advantage of" question cold.Ready
3 - Storage Management: NVM Scheduling & the File System InterfaceTwo layers of the storage stack that get tested with look-alike questions. Learn which one allocates memory and which one gives you files.Ready
4 - Hyper-Threading (HTT): One Core, Two ProcessorsThe feature that lets a single physical processor act like two — plus the acronyms you should not mix it up with.Ready
5 - The Memory Hierarchy: ROM, Cache, RAM, Virtual RAMOne ladder of memory, from the tiny-and-fast to the large-and-slow. Learn it once and three exam questions (Q12, Q13, Q14) answer themselves.Ready
6 - RAM Technologies: DRAM, SRAM, and Clock SignalsFour RAM types that the exam tests as look-alike pairs. Learn the refresh question and the clock question, and Q15 + Q16 become free points.Ready
7 - Thermal Troubleshooting: Overheating & ShutdownsThe last Hardware lesson. When a machine overheats and shuts down, the fix is almost always airflow — not the battery, RAM, or OS.Ready
