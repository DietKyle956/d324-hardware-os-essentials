Memory Hierarchy Cheat Card

Level (fast → slow)Key fact
L1 cacheSmallest · fastest · closest to the core
L2 cacheMiddle — larger & slower than L1
L3 cacheLargest & slowest of the caches
RAMVolatile main memory
Virtual RAMPaging file on a drive; extends RAM
Storage (SSD/HDD)Slowest · largest · permanent

Memory hooks

  • L1 = level 1 = closest to the CPU = smallest and fastest. Level number up → size up, speed down.
  • ROM is read-only and non-volatile — it holds firmware and doesn't change over the computer's life.
  • Volatile (RAM/cache) loses data on power-off; non-volatile (ROM, SSD, HDD) keeps it.
