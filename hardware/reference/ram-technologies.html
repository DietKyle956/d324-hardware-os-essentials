RAM Technologies Cheat Card

TypeKey fact
DRAMDynamic — capacitors leak, needs constant refresh; main memory
SRAMStatic — flip-flops, no refresh; faster, pricier; used for cache
SDRAMSynchronous — shares a common clock with the system bus
Asynchronous DRAMIndependent of the CPU's external clock (no shared clock)
DDR SDRAMDouble data rate — transfers on both clock edges

Memory hooks

  • Sync = same clock. Async = its own clock.
  • Dynamic = needs refresh. Static = doesn't.
  • DDR = double data rate (both rising and falling edges).
