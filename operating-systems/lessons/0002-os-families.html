OS Families: Client vs Server

Not all operating systems are the same kind. Learn to sort one into client, server, or mobile — and spot the "not an OS" trap.

The win

By the end of this lesson you'll classify any OS on sight and catch distractors like Microsoft Azure, which looks like an OS but isn't.

The client–server picture

Three real families — and one imposter

FamilyPurposeExamples
Client (desktop)Interactive end-user workstationsWindows 11, macOS
ServerServe many clients; host servicesRed Hat Enterprise Linux, Windows Server
MobilePhones & tabletsSymbian OS, Android, iOS
Not an OSCloud computing platformMicrosoft Azure

The trap

Microsoft Azure is a cloud platform, not an operating system. It provides hosted services (compute, storage, databases) that run on top of operating systems. Don't let the familiar name fool you.

A server OS is optimized to serve many clients at once and run services (web, database, authentication) reliably around the clock — often with no graphical desktop. A client OS is built for one interactive user at a workstation. A mobile OS targets phones and tablets.
