Network Hardware by OSI Layer

Four devices, two layers. Know what lives at Layer 2 and what provides centralized connectivity.

The win

By the end of this lesson you'll know a switch works at Layer 2 and provides centralized connectivity (Q33) — and how it differs from patch panels, hubs, and routers.

The four devices

DeviceOSI layerWhat it does
Patch panelLayer 1 (physical)Passive termination point; organizes cable runs; no intelligence
HubLayer 1 (physical)Repeats a signal out every port; no addressing
SwitchLayer 2 (data link)Forwards frames to the specific port using MAC addresses
RouterLayer 3 (network)Routes packets between different networks using IP addresses

A switch operates at Layer 2. It learns which device is on which port by MAC address and sends each frame only to the intended port. That makes it the device that provides centralized connectivity — many devices plug into one switch and reach each other efficiently.

A router works one layer up, at Layer 3, moving packets between networks using IP addresses. A hub is a dumb Layer 1 repeater that floods every port. A patch panel isn't even powered — it's just a tidy place to terminate cables.

The trap

"Layer 2 + centralized connectivity" = switch. Hubs also give you a central box, but they're Layer 1 and don't forward by address — they flood. Routers are Layer 3 and connect between networks, not devices within one.
