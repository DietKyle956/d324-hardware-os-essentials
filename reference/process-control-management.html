Process states

Ready — wants the CPU. Running — has the CPU. Waiting (blocked) — paused on an event (e.g. disk read). When the event completes, Waiting → Ready.

Memory hook

Process control = tracks processes. Memory = RAM. Scheduling = picks next. Storage = disk. "Run it or wait for an event" is always process control.
