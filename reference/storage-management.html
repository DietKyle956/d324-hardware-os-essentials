Memory hook

File system = files. NVM scheduler = memory blocks.
One gives you files to manage; the other decides where the bits physically go.

Key facts

  • NVM = non-volatile memory (keeps data without power — SSD/flash).
  • NVM scheduling = managing the allocation of that memory.
  • File system interface = the operations (create/open/read/write/delete) that let the system access and manage files.
