Cheat Sheet — SSD vs HDD

FactorSSDHDD
Data transfer speed✔ winsSlow (mechanical seek)
Cost per byteHigher✔ wins (cheaper)
Capacity per dollarLower✔ wins (more for the money)
Shock / durability✔ wins (no moving parts)Fragile
Write enduranceFinite (cells wear)✔ wins (far more rewrites)
Power / heat / noise✔ wins (less)More

Memory hook

SSD = no moving parts → faster, tougher, pricier per byte, finite writes.
HDD = spinning platters → slower, fragile, cheaper, huge capacity per dollar.

Trap

"Unlimited write operations" is never an SSD advantage. Flash cells wear out after a finite number of write/erase cycles.
