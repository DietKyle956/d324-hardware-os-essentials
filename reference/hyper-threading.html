Cheat Sheet — Hyper-Threading (HTT)

TermWhat it isWhat it does
HTTHyper-threading technologyOne physical processor acts as two logical processors
CMOSComplementary metal-oxide-semiconductorBattery-backed chip storing BIOS/UEFI settings
PCIPeripheral component interconnectExpansion bus for add-on cards
HDDHard disk driveStorage

Memory hook

HTT = one core, two logical processors. It exposes one physical core to the OS as two, letting two threads run "at the same time" — not two physical cores, not doubled speed.
