Authentication and Defense

Centralized logins and the two intrusion systems. Know which one is passive.

The win

By the end of this lesson you'll know a Domain Controller is the centralized authentication server (Q23), and an IDS is the passive defender (Q24) — while an IPS acts.

Centralized authentication

A Domain Controller is the Windows server that centralizes authentication. Users log in once and the domain controller validates their credentials against a central directory, rather than each computer keeping its own user list.

IDS vs IPS

DeviceBehaviorPosition
IDS (intrusion detection system)Passive — watches and alerts, doesn't blockMonitors a copy of traffic
IPS (intrusion prevention system)Active — detects and blocks/preventsSits inline in the traffic path

The word to remember: an IDS only detects and alerts — it offers passive protection. An IPS prevents, actively dropping malicious traffic as it passes through.

The trap

"Passive protection" = IDS (detect + alert only). "Prevents/blocks" = IPS. The letters tell you the job: Detection vs Prevention.
