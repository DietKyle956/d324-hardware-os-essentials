The coaching report

The pre-assessment coaching report (d324_oa_topics_and_questions.md) is the source of truth for which question types the assessment tests and which ones were missed. Every lesson is aligned to an actual exam question, and the missed questions are the priority queue. It stays out of the public repository on purpose.
