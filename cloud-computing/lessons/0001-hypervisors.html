Hypervisors: Type 1 vs Type 2

Two ways to run virtual machines. Know where each hypervisor sits in the stack.

The win

By the end of this lesson you'll know a type 2 hypervisor runs on top of the host operating system — the exact distinction you missed (Q55).

The two types

TypeRuns onAlso calledExample
Type 1Directly on physical hardwareBare-metalVMware ESXi, Hyper-V
Type 2On top of a host operating systemHostedVirtualBox, VMware Workstation

A type 2 hypervisor is an application installed on an existing OS (Windows, macOS, Linux). It operates on the host operating system, and guest VMs run above it. That's why it's called "hosted."

A type 1 hypervisor skips the host OS entirely and installs directly on the physical hardware — more efficient, used in data centers.

The trap

The question asks where a type 2 hypervisor operates: on the host operating system. Type 1 operates on the physical hardware. Don't pick "guest operating system" or "virtual application" — those sit above the hypervisor, not below it.
