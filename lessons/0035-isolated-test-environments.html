Isolated Test Environments: VM vs Container

When someone needs a safe, isolated place to test software, reach for a virtual machine.

The win By the end of this lesson you'll know the solution for an isolated computing environment for testing software is to configure a virtual machine — the exact distinction you missed (Q59).

The scenario

Someone needs an isolated computing environment to test software safely. The right move is to configure a virtual machine. A VM gives a complete, isolated computer — its own OS and virtual hardware — so tests can't touch the physical machine.

OptionIs it an isolated test environment?
Configuring a virtual machineYes — full isolated environment for testing
Cloud-based storageNo — stores files, doesn't run/isolate tests
Creating a containerIsolates an app, but shares the host OS — not a full environment
Adding more memoryNo — performance, not isolation
The trap The exam's answer for "isolated environment for testing software" is configure a virtual machine. A container also isolates, but it's lighter-weight and shares the host OS — the OA treats the VM as the complete isolated test environment. Storage and RAM don't provide isolation at all.
