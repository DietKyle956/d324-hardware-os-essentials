Containers: Process Isolation and the Shared Host OS

Containers are light because they share one OS and isolate at the process level — not the machine level.

The win By the end of this lesson you'll know containers use process isolation (Q57) and share the same host operating system (Q58) — both of which you missed.

What makes a container a container

TraitContainerVirtual machine
IsolationProcess-levelMachine-level (full virtual hardware)
OSShares the host OSEach VM has its own guest OS
OverheadLightweight, fastHeavier, slower

Every virtualized container uses process isolation — each container's processes are walled off from the others and the host, but they all run on the same host operating system kernel. There's no separate guest OS per container, which is why containers start fast and use few resources.

A virtual machine is different: it has machine-level isolation and runs its own guest operating system on virtualized hardware.

The trap Two facts define containers: process isolation (not machine isolation) and sharing the host OS (not a dedicated guest OS). "Machine-level isolation" and "dedicated guest OS" describe VMs — flip them and you've answered wrong.
