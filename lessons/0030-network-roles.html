Network Roles: Client, Server, Peer

Who asks, who serves, and who does both. Assign the role by what the device does.

The win By the end of this lesson you'll assign roles by behavior: a requestor is a client (Q45, Q47), and a printer serving jobs is a server (Q46).

The three roles

RoleWhat it doesExam tell
ClientMakes requests to a server"makes requests", "browsing/editing"
ServerProvides a service to clients"provides/prints/serves"
PeerActs as both client and server"equal roles", "shares both ways"

The rule: ask what the device does. An application that makes requests to a database is a client. A workstation used for spreadsheets and browsing is a client — it requests services. A printer that prints documents for users is a server — it provides a service.

The trap Don't think of "client" and "server" as hardware types — they're roles. The same box can be both. In these questions, the verb decides: requests → client, provides/serves → server.
