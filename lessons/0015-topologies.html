Network Topologies

Four basic layouts — bus, star, ring, mesh. Know each one's cost, ease, and failure story.

The win By the end of this lesson you'll know bus is cheap and easy to install but hard to reconfigure (Q32), and mesh provides multiple pathways between nodes (Q35).

The four layouts

TopologyShapeStrengthsWeaknesses
BusAll nodes tap one backbone cableCheap, easy to installHard to reconfigure; a break affects all
StarAll nodes connect to a central hub/switchEasy to add/remove nodes; easy to troubleshootCentral device is a single point of failure
RingEach node connects to two neighbors in a loopOrderly, predictable data flowA break can disable the loop
MeshNodes connect to many othersMultiple paths; very fault-tolerantExpensive; lots of cabling

A bus uses a single backbone cable everyone taps into. It's cheap and simple to install — but because everything rides one cable, it's difficult to reconfigure, and one break can take the whole segment down.

A mesh connects nodes to multiple other nodes, giving multiple pathways between any two. If one link fails, traffic reroutes. That redundancy costs more cabling and money.

The trap "Cheap and easy to install but difficult to reconfigure" is bus. Don't confuse it with star (easy to reconfigure via the central device) or mesh (fault-tolerant but not cheap). And "multiple pathways" always means mesh.
