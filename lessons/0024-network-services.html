Network Services: Load Balancing and CaaS

Two services that keep things moving: one spreads traffic, the other spreads communication tools.

The win By the end of this lesson you'll know load balancing distributes traffic across multiple servers (Q25), and Communications as a Service (CaaS) covers VoIP, instant messaging, and video collaboration (Q26).

Load balancing

Load balancing distributes incoming traffic across multiple servers that can each fulfill the same task. If one server is busy or fails, the load balancer routes work to the others — improving availability and performance.

Communications as a Service (CaaS)

CaaS delivers communication capabilities over the internet/cloud — Voice over IP (VoIP), instant messaging, and video collaboration — without the company hosting its own phone or conferencing infrastructure.

The trap "Distribute traffic across servers doing the same task" = load balancing. Don't confuse it with web hosting (just serving sites) or centralized computing. For the "as a service" list, remember: CaaS = Communications (voice, messaging, video).
