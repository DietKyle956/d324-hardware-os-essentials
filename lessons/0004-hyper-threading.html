Hyper-Threading (HTT): One Core, Two Processors

The feature that lets a single physical processor act like two — plus the acronyms you should not mix it up with.

The win By the end of this lesson you'll know what hyper-threading does, what it doesn't do, and what CMOS and PCI actually are — so Q11 and its look-alikes are automatic.

Physical cores vs logical processors

Hyper-threading technology (HTT) — Intel's name for simultaneous multithreading — lets one physical processor perform as two processors at the same time. Each physical core shows up to the operating system as two logical processors, so the OS can schedule two threads on that one core.

It isn't two physical cores, and it doesn't double raw speed. The trick is that a core is often idle waiting on memory or a cache miss — HTT lets a second thread use those otherwise-wasted execution units in the same moment.

Don't mix these up

The exam pairs HTT with three unrelated hardware acronyms. Know all four:
