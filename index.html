Study workspace for the WGU Objective Assessment.

Roadmap Mission Resources

Module 1 — Explains Design Decisions (33%)

Hardware Q6–16

  • Storage anatomy: platters, tracks, sectors, read/write heads ⚠ missed Q6
  • SSD vs HDD: trade-offs and when each wins
  • Storage management: NVM scheduling and the file system interface
  • Processor virtualization: hyper-threading (HTT)
  • Memory hierarchy: ROM, L1/L2/L3 cache, virtual RAM ⚠ missed Q13
  • RAM technologies: DRAM vs SRAM, synchronous vs asynchronous, DDR SDRAM ⚠ missed Q15
  • Thermal troubleshooting: overheating, vents, fans

Operating Systems Q1–5

  • Where the OS lives at runtime: RAM as the system-code workspace
  • OS families: client vs server operating systems
  • Kernel building blocks: process control management ⚠ missed Q3
  • OS interfaces: GUI vs CLI trade-offs
  • System calls and the POSIX API ⚠ missed Q5

Virtual Environment Q17–20

  • Cloud characteristics: resource pooling, measured service, elasticity ⚠ missed Q17
  • Virtualization tools: sandbox, test development, app/cross-platform virtualization

Module 2 — Develops Topologies (33%)

Networking Q32–40

  • Topologies: bus, star, ring, mesh ⚠ missed Q32
  • Network hardware by OSI layer: patch panels, hubs, switches, routers
  • Twisted-pair cabling: Category ratings and speeds ⚠ missed Q34
  • Network scope: PAN, LAN, MAN, WAN
  • Malware taxonomy: armored, boot-sector, companion, macro, polymorphic ⚠ missed Q37
  • Attack vectors: social engineering and related threats

Non-functional Requirements Q21–26

  • Non-functional requirements: availability, reliability, usability, scalability
  • Network auto-configuration: DHCP and APIPA ⚠ missed Q22
  • Authentication and defense: Domain Controller, IDS vs IPS
  • Network services: load balancing and Communications-as-a-Service

IDEs and Text Editors Q27–31

  • IDEs vs text editors: choosing the right tool
  • Language models: compiled vs interpreted/scripting
  • Paradigms and tools: OOP languages (C++) and PowerShell cmdlets

Module 3 — Explains Configuration and Deployment (33%)

Customization Q41–54

  • Storage configuration: NAS sizing, rotational speed, energy
  • Capacity planning: RAM arithmetic
  • Network roles: client, server, peer
  • Web-stack roles: front-end vs back-end and databases
  • Tech stacks and web servers: Apache, frameworks ⚠ missed Q52

Cloud Computing Q55–60

  • Hypervisors: type 1 vs type 2 ⚠ missed Q55
  • Containers: process isolation and the shared host OS ⚠ missed Q57, Q58
  • Isolated test environments: VM vs container ⚠ missed Q59
  • Cloud service models: SaaS, IaaS, PaaS, HaaS
